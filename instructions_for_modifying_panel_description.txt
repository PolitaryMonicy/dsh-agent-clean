你的 profile 通过 link: 直接指向这个仓库，因此改完不需要复制到别处，下次加载就是新文本。

改动时的三个注意事项
只修改引号或反引号里的字，不要改动 ${value.sessionsRoot} 这类插值、括号配对和拼接结构。
保持编码为 UTF-8 无 BOM、固定使用 LF（用 VS Code 最省事；不要用 PowerShell 的 Set-Content -Encoding utf8，它会加 BOM）。
保存后验证：运行 node --check plugin\client.js；如果想更稳妥，再运行 node test\client-slot-probe.mjs，它应当输出 A=PASS B=PASS C=PASS。
